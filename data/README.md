# Input data

The analysis expects the merged participant workbook here:

    data/Merged_Data_2.xlsx

This file is **not distributed** with the repository. It contains potentially
identifying clinical and laboratory data from children enrolled in Blantyre, Malawi.

De-identified data supporting the findings of the study are available from the
corresponding author (llsibale@gmail.com) on reasonable request, subject to approval
by the relevant research ethics committee and a data transfer agreement.

`verify_lab_controls.py` additionally takes the laboratory register as its second
argument; that file is likewise not distributed.
